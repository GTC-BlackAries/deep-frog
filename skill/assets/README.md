Use it only to identify the Deep Frog project and its reports. Keep the image unchanged, preserve its square aspect ratio, and embed it into generated HTML as a PNG data URI. The logo is a brand asset and is not a generic MIT-licensed illustration; see the `LICENSE` in the skill root (`../LICENSE`) for the brand-mark use note.
