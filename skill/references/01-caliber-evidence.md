# 口径与证据纪律

> 写正文前必读。这一份是本 skill 的核心资产——**方法论会过时，纪律不会**。

## 一、口径清单：每个数字必须交代什么

一个数字脱离口径就是噪音。**正文里出现的每个规模、比例、增速，必须能回答下表全部问题**：

| 维度 | 要交代什么 | 反例（不可用） | 正例（可用） |
|---|---|---|---|
| **统计方法** | 自报 / 确诊 / 检出 / 激发试验确诊 / 登记 | 「患病率 40.9%」 | 「家长自报孩子曾或正在发生过敏性疾病 40.9%；医生确诊食物过敏 2.5%」 |
| **分母** | 分子分母各是什么、年龄范围 | 「4.81% 的儿童」 | 「0–5 岁儿童自报食物过敏 4.81%（n=70,107，31 省 275 监测点）」 |
| **品类边界** | 含什么、不含什么 | 「儿童防敏市场 1095 亿」 | 「儿童防敏零售市场 1095 亿元（2025，零售额，含低敏奶粉/营养品/洗护，不含辅食）」 |
| **价格口径** | 零售额 / 出厂额 / GMV | 「市场规模 716 亿」 | 「辅食零售额 716 亿元（2025，艾媒口径；华经口径 619.6 亿）」 |
| **时间** | 年份、是否滚动、基期 | 「CAGR 22%」 | 「2026E CAGR 22%（渠道大会口径，无第三方报告背书）」 |
| **来源性质** | 官方统计 / 第三方研究 / 品牌 PR / 自媒体 | 「市场规模将突破 80 亿」 | 「2026E 突破 80 亿元（CAGR 22%）——来源为品牌 PR 稿，机构与口径均未标注，不可用作决策依据」 |
| **地域** | 中国 / 全球 / 某区域 | 「最常见过敏原是鸡蛋」 | 「全国 13.87 万人荟萃：鸡蛋 27%、螃蟹 27%、牛奶 22%；但北方（天津/陕豫内蒙古）0–6 岁首位过敏原为小麦（11.6%–22.4%）」 |
| **样本代表性** | 中心/单中心 vs 多中心 vs 全国 | 「患病率 7.7%」 | 「重庆单中心三次横断面 3.5%→7.7%→11.1%；综述原文提示『诊断敏感>特异，存在被放大的可能』」 |

### 三个高频口径陷阱（每次写规模必查）

1. **自报 vs 确诊差一个数量级。** 家长自报"有过过敏症状"通常远高于医生确诊的具体疾病。
   用自报率推市场 → 严重高估。**报告里两个数都要给，并明确点出差距。**
2. **"含某品类"与"不含某品类"是两个市场。** 检索到的市场规模若口径不明，
   很可能是一个包含你研究对象的**更宽口径**。看到大数先问"含不含"。
3. **品牌 PR ≠ 第三方报告。** PR 稿没有机构背书、没有口径说明、且天然夸大。
   这类数字**只能出现在"口径冲突"表里**，不能出现在结论段落。

### 第四个陷阱：同一指标在时间轴上换了定义（纵截面陷阱，最难发现）

前三个是**横截面**陷阱——同一时点、两个口径。而这一类是**纵截面**陷阱：
**数据看起来是连续的、每个点都有来源，但拼接出来的趋势里有一部分是口径变更制造的假趋势。**

**这类数据的典型特征**（识别用，不必复现具体案例）：
- 发布方在研究区间内**改过指标定义**（行业标准换版、统计口径重构、分类阈值调整）；
- 早期年份的关键分类**当时可主观归类、后来才被量化**——于是早期数据带上了主观性；
- "全国/全球平均值"本身是**第三方对分散个体财报的主观归一化**，且可能被事后修正；
- 结果：曲线看起来连续、每个点单独看都合格有出处，**但趋势里有一段是口径变更造出来的**。

**为什么它比横截面陷阱更难发现**：它不会让任何单个数字看起来可疑。
每个点单独看都合格、有出处、精度也对，只有把整条序列画出来看趋势，裂缝才显形。

**检查动作三连（研究长时序指标时必做）**：
1. 这个指标的定义/口径在研究区间内**改过吗**？（查发布方的历次指引更新、版本说明）
2. 改的那一年**是哪一年**？（在时间轴上标出"口径断点"，而不是平均处理）
3. 跨越断点的序列**能拼接吗**？不能就在图上和表里**显式断开**，并说明断点前后不可比。

**产出要求**：凡给出跨越 10 年以上的逐年序列，必须在图注/表注里写明口径断点在哪一年。
把"整段连续曲线"呈现给读者而不标断点，等于把口径变更伪装成趋势。

### 冲突数字的处理规则

两个来源打架时：

| 做法 | 判断 |
|---|---|
| 挑一个顺眼的用 | ✗ 禁止 |
| 取平均 | ✗ 禁止（两个口径不同的数平均无意义） |
| 只写"约 X 亿" | ✗ 禁止（掩盖了不确定性） |
| **并列写出，标注各自出处、口径、可信度，然后说明"因此该数字不可用作决策依据"** | ✓ 正确 |

冲突本身是**高价值信息**：它通常意味着该领域缺乏统一口径，这本身就是一条洞察。

## 二、证据分级

每条关键论断都要标等级。等级标注不是形式主义——它告诉读者**这条能扛多大的决策重量**。

| 等级 | 含义 | 例子 |
|---|---|---|
| **A** | 指南 / 系统综述 / meta 分析 / 随机对照试验 / 官方统计 | 《中国食物过敏诊疗指南》、全国流调 |
| **B** | 队列研究 / 观察性数据 / 主流研究机构口径 | 厂商财报、行业白皮书（标明机构） |
| **C** | 专家意见 / 科普 / 企业资助研究 / 自媒体 | 品牌 PR、博客、访谈 |

**关键规则**：
- **A 级也有局限**。系统综述的质量取决于纳入研究的质量；指南会过时；
  RCT 的人群常常很窄。**"这是 A 级"不等于"这可以直接套到我的场景"**。
- **关键结论必须写清适用人群**。"高危人群有效" ≠ "普通人群有效"；
  "实验室条件下" ≠ "真实世界"。适用范围被外推是最高频的错误。
- **效应量必须紧邻研究名**（队列/RCT/PMID/DOI），裸奔的 "RR 0.49" 无可追溯性。

### 结论型数字的额外要求

凡出现「降低 X%」「提升 Y%」「风险下降 Z%」这类**结论型数字**，必须同时有：
证据等级 + 人群 + 终点指标 + 随访年限 + **以及被省略的那一半**。

> 正确示范：「早引入过敏原降低食物过敏风险约一半（A：JAMA Peds 2023，n=13,794，RR 0.49），
> **但退出率升高（RR 2.29，每千人多 258 例退出）**——依从性决定实际效果。」

省略后半句就是误导。`audit_report.py` 会专门查这一项。

## 三、误引排查表

被广泛传播的"共识"经常是二手简化版。**每个进入正文的关键论断动手前必查**：

| 检查项 | 问法 | 典型翻车 |
|---|---|---|
| 文献真的存在吗 | 标题+作者+年份+期刊，多路检索交叉 | 广为流传的综述其实只有 protocol，从未作为完整综述发表 |
| 题名/年份/期刊没错配 | 逐字比对原刊 | 把 A 期刊的试验记成 B 期刊发表 |
| 两篇被混为一谈 | 是同一研究吗 | "EAT"与另一项同期试验常被混称为同一研究 |
| 结论是哪个分析集 | ITT 还是 PP/亚组 | 阳性的主要来自依从者子集，ITT 为阴性——只报阳性结论 |
| 省略的另一半 | 退出率/副作用/适用限制 | 只报疗效不报退出率，导致"零成本干预"的错觉 |
| 适用人群 | 高危→普通？实验室→真实世界？ | 高危人群的结果被当成普适建议 |
| 谁在引用它 | 引用时改口径了吗 | 自报率被下游当作确诊率使用 |
| 是否已被取代 | 有更新的版本/共识吗 | 2022 年的结论被 2025 年的指南推翻 |

### 三个必做的动作

1. **追到原文。** 二手转述至少退一步，找到指南原文 / 论文摘要 / 官方通稿。
2. **多个独立来源验证。** 同一事实至少两条独立来源，或一条一手来源。
3. **纠错单列一节。** 发现误引时，在报告里写明：
   > 「XX 结论出自 NEJM 2016 而非 Lancet 2022——后者是另一项试验；
   > 且其 ITT 分析为阴性，阳性主要来自 per-protocol 子集。」

   **这一节往往比正文结论更有价值**，也最能建立可信度。

## 四、诚实标注（比什么都要重要）

### 必须标注的情况

| 情况 | 标注方式 |
|---|---|
| 查不到数据 | 「未查到公开数据」——**绝不用估算填空** |
| 只有 PR 稿来源 | 「（品牌 PR 稿，无第三方背书，不可作决策依据）」 |
| 两个数打架 | 列表呈现 + 「不可调和」 |
| 存疑引文 | 「（未查到原始研究来源，存疑）」 |
| 估算值 | 「（估算）」并说明推算方式 |
| 单中心数据 | 「（单中心，不能外推）」 |
| 本地/区域性数据 | 标注适用地区 |
| **核验没跑成**（限流 / 网络 / 工具报错 / agent 崩了） | 「**未验证**：核验环节未跑通，不是这条被证伪」——**见下面三态纪律** |
| **某一路 agent 空返回** | 「NO DATA：本路未取回（原因 X）」——不许把别的路的结论匀过来填空 |

### 三态判定：confirmed / refuted / unverifiable

**必须区分"这条被反驳了"和"这条没能验证"，两者在产出里的处置完全不同。**

| 状态 | 判定 | 处置 |
|---|---|---|
| **confirmed** | 找到出处且经得起对抗式核验 | 进正文，带口径 |
| **refuted** | 找到反证 / 原文不支持 / 已被更权威版本取代 | 单列纠正，写进"被误解的结论"或"已证伪"章节 |
| **unverifiable** | 核验环节失败、限流、工具报错、查不到原文 | **进"未解缺口"，不许写成 refuted，也不许偷偷当 confirmed 用** |

> 这条看起来琐碎，实践里最常出事：**核验把自己搞崩了（比如触发限流），
> 模型会默认把"没查到反证"读成"大概没问题"，于是整份调研在一个静默故障中降级成"全都过"。**
> 失败也是一种结论，但它属于"未验证"，不属于"通过"。

### 不要做的

- 用"约"掩盖一个本该标"未查到"的缺口
- 用"业内普遍认为"给没有出处的结论背书
- 把"某个专家说"写成"研究证明"
- 把自己的推算写成"数据显示"
- **把"核验没跑通"写成"该结论已被证伪"**——工具故障不是研究发现

> `audit_report.py` 认得上述诚实标注词（"未查到""存疑""口径""估算""不可调和"等），
> 命中即豁免。**所以标注诚实反而能让审计通过——标注与质量是同向的。**

## 五、交付前自检清单

```bash
python scripts/audit_report.py {报告路径}     # ERROR 必须清零
```

人工再过一遍：

- [ ] 每个数字都能回答口径清单的 8 个问题吗？
- [ ] 冲突数字都并列呈现了吗？还是被悄悄换掉了？
- [ ] "未解缺口"章节列全了吗？有没有用估算填充？
- [ ] 每条关键论断的**适用人群**写了吗？
- [ ] 每个结论型数字都带了证据等级 + 被省略的那一半吗？
- [ ] 引用都能追到原文吗？存疑的都标注了吗？
- [ ] 免责声明在首尾都有吗？
