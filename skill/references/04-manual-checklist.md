# 交付前人工核对清单（无 Python 时的等价路径）

> **什么时候用**：运行环境没有 Python 3.8+（含 Windows 应用商店版占位符 `python.exe`）时，
> 走 SKILL.md 第 6 步的**路径 B**。
> **不可跳过**。自检是本 skill 唯一的机器化兜底，跳过它等于交出一份没验过的报告。
>
> **与 `audit_report.py` 的关系**：本清单是该脚本**全部检查项的人工等价物**。
> 脚本能查的，这里都能查；脚本查不了的（渲染塌陷、口径是否真的到位），这里要求人工判断。
> **不许因为跑不了脚本就少查一项。**

## 使用方式

逐条过，**每条要么通过，要么记录问题并处理**。检查结果写进交付说明：
「本次为人工核对（无 Python 环境），共查 N 项，发现 M 处问题，处理情况：……」。

---

## A 组 · 数字体检（对应脚本 `check_numbers` / `check_fake_precision`）

- [ ] **A1 裸数字**：正文里每个 `%`、金额、人数、条数，前后 40 字内能找到口径限定词
      （口径/占/约/达/为/自报/确诊/队列/随机/年份/来源/率/第…）。
      找不到的，补口径或删掉——**没有口径的数字不许留在正文**。
- [ ] **A2 枚举不误判**：成组列举的数字（用顿号串起来的同类项）只要组内第一项带了口径，
      后续项可不再重复标注。
- [ ] **A3 伪精确**：没有哪个"率/占比/比例/渗透率/CAGR"带了 4 位以上小数。
      - 排除项：DOI（`10.xxxx/…`）、PMID 不是伪精确。
      - 真的需要这么精确 → 它是实测值，不是估算值。

## B 组 · 引用体检（对应脚本 `check_citations` / `check_effect_sizes`）

- [ ] **B1 具体来源可追溯**：提到 NEJM / Lancet / JAMA / Cochrane / BMJ / JACI / 中华儿科杂志 /
      中华流行病学杂志 / 白皮书 等**具体可考**的名称时，邻近 120 字内有 DOI / PMID / PMC /
      年份 / 链接。**没有就补上，或改成泛指表述。**
- [ ] **B2 泛指词不误伤**：「指南」「共识」「meta 分析」「系统综述」「研究」「试验」作泛指时
      **不算问题**；只有写成「XXX指南（2022）」这种带年份补全、而邻近又无任何来源标识时才需要处理。
- [ ] **B3 效应量有出处**：每个 `RR` / `OR` / `HR` / `AUC` / `CI` / `NNT` 数值，
      邻近 150 字内有研究标识（队列 / RCT / 随机 / 对照 / meta / PMID / DOI）。
      - 正确：「早引入过敏原降低风险约一半（队列研究，RR 0.49）」
      - 错误：孤零零一个「RR 0.49」

## C 组 · 论断与证据（对应脚本 `check_claims_vs_evidence`）— **这组是硬伤，零容忍**

- [ ] **C1 结论型数字都有证据**：凡「降低 X%」「提升 Y%」「风险下降 Z%」「改善 N%」
      「有效」「获益」这类说法，邻近 160 字内必须同时出现：
      - 证据等级标记（已确证 / 已证实 / 证据等级 A / 随机 / 对照试验 / RCT / 指南 / 共识 / meta）
      - **或** 免责标注（存疑 / 未查到 / 宣称 / 声称 / 说法 / 可能 / 疑似 / 据说）
- [ ] **C2 转述不算背书**：写「某研究说 X」时带「宣称 / 声称 / 说法 / 据称」等转述词，
      不构成背书；**但不能因此省略被省略的那一半**（见 C3）。
- [ ] **C3 被省略的另一半**：每个「干预有效」类结论，都写清了**退出率 / 副作用 / 适用人群限制**
      中至少一项。没写 = 误导。

## D 组 · 必备内容（对应脚本 `check_required`）— **缺一项即为交付失败**

- [ ] **D1 口径说明**：报告里有明确的口径交代章节或段落
- [ ] **D2 未解缺口**：有「未解缺口 / 缺口 / 未查到 / 待补」章节，且**用估算填过坑的地方没有**
- [ ] **D3 免责声明**：首尾都有，且写明不构成医疗/法律/金融建议
- [ ] **D4 证据分级标记**：出现 A / B / C 等级标记，或「已确证 / 已证实」这类判定词

## E 组 · 离线可用（对应脚本 `check_offline`）

- [ ] **E1 无外部资源**：`<script src>` / `<img src>` / `<iframe src>` / `<link href>`
      **没有指向外部域名**。
      - 允许清单：`cdnjs.cloudflare.com`、`esm.sh`、`cdn.jsdelivr.net`、`unpkg.com`
      - **字体必须本地打包**（本 skill 已带 `fonts/`）
      - 图片一律内联 SVG / CSS
- [ ] **E2 `<a href="http…">` 不算问题**：那是参考文献超链接，不影响离线阅读，不要误判。

## F 组 · 链接与 CSS（对应脚本 `check_internal_links` / `check_mobile_css`）

- [ ] **F1 内部锚点无死链**：每个 `href="#x"` 都有对应的 `id="x"`
- [ ] **F2 有窄屏适配**：存在 `@media (max-width: …)` 媒体查询
- [ ] **F3 有打印样式**：存在 `@media print`
- [ ] **F4 窄屏 flex 转竖排**：窄屏块内有 `flex-direction: column`
      （漏这行 → 侧栏会被压成窄条，内容被甩到屏幕两端）
- [ ] **F5 侧栏窄屏兜底**：侧栏在窄屏下是 `flex: 1 1 auto; min-width: 0`，
      **不是 `flex: none`**（`flex: none` 会按 max-content 算宽度，撑出视口）

## G 组 · 渲染实检（对应脚本 `render_check.py`）— **脚本替代不了，只能人工看**

> 脚本能做的是截图；**判断"截出来对不对"仍然要人看**。路径 B 下这一步更不能省。

- [ ] **G1 打开报告，肉眼扫一遍**：没有空白页、没有内容被压扁成一条、没有大段重叠
- [ ] **G2 章节齐全**：每个 `<h2>` 章节都有实际内容，没有空壳标题
- [ ] **G3 表格不溢出**：宽表格在窄屏下横向滚动，而不是撑破版面
- [ ] **G4 图片/图表不缺失**：没有裂图、没有空白占位
- [ ] **G5 字体生效**：标题与数字是 Quicksand / Nunito（圆润西文），
      没有回落成默认衬线体。**如果回落了，说明 `fonts/` 目录没跟 HTML 一起分发**——
      提醒用户「HTML 必须连同 `fonts/` 目录一起使用」。

## 常见问题速查

| 症状 | 多半是 | 怎么办 |
|---|---|---|
| 截图出来是空白页 | 无头浏览器里 `scrollTo` 不生效 | 按 `<h2 id=>` 拆章分别截；或直接人工开浏览器逐章看（G1） |
| 截出来是一条极窄的竖线 | Edge 无头最小窗口宽度约 500px，截窄屏产生假象 | 窄屏验证用 ≥560px 宽度，别用 375/420px |
| 中文文件名截图报 `ERR_NAME_NOT_RESOLVED` | URL 被编码成 punycode | 复制成 ASCII 副本再截 |
| 字体看着是默认字体 | `fonts/` 没跟着 HTML 一起分发 | 提醒用户连同 `fonts/` 目录分发；字体为 SIL OFL 1.1，允许随包分发 |
| 页面顶部有大片空白 | `body` 有 `::before` 装饰层 | 打印样式里 `body::before{display:none}`（见 `03-report-design.md`） |

## 交付说明里必须写清的两件事

1. **本次自检走的是脚本还是人工**——写「本次为人工核对（环境无 Python 3.8+）」。
2. **核对结论**——查了几项、发现几处、怎么处理的。
   **不许写「脚本跑不了，跳过自检」**——那是把最重要的兜底丢掉。
